# SNUGDOG mascot pipeline (terrier)

The brand character: a charcoal Scottish-terrier type with a beard, heavy brows,
upright ears, wide expressive eyes and a red collar. It was built to follow a
reference image the client supplied, as an original model in that likeness.
Everything is generated by script in headless Blender, so it is reproducible.

**Brand rule: the hot dog is the product, the dog is the mascot. They never share a
scene, and the dog never touches, holds or eats food.** (This is also why the bone
from the reference image was left out.)

The earlier dachshund mascot is archived, complete and runnable, in
`assets/3d/mascot-dachshund-v1/`.

```bash
npm run 3d:mascot                    # full build: GLBs + furred stills + turntable
npm run 3d:mascot -- -- --no-render  # GLBs and .blend only
npm run 3d:mascot -- -- --preview    # quick two-view check, no exports
npm run 3d:mascot -- -- --preview --pose 02_Curious
npm run 3d:mascot -- -- --preview --no-fur   # the bare model, fast
```

## Layout

| Folder      | Contents                                                           |
| ----------- | ------------------------------------------------------------------ |
| `scripts/`  | `anatomy.py`, `modeling.py`, `rig.py`, `build_mascot.py`           |
| `source/`   | `SNUGDOG_Terrier.blend` (rigged, groomed, pose library as actions) |
| `textures/` | Baked skin maps: albedo, normal, ORM at 2K, plus `_1k` copies      |
| `renders/`  | Cycles stills (PNG master + cleaned WebP cutout) and the turntable |
| `exports/`  | `SNUGDOG_Terrier.glb`, `SNUGDOG_Terrier_hero.glb`                  |

Published copies go to `public/models` and `public/images/mascot`.
Shared helpers (studio, baking, export) come from `assets/3d/scripts`.
Files named `SNUGDOG_Dachshund*` or `dachshund_*` left in these folders are stale
outputs from the previous character and can be deleted.

## Outputs

| File                              | What                                              |
| --------------------------------- | ------------------------------------------------- |
| `SNUGDOG_Terrier_pose_<id>.webp`  | One furred still per pose: what the site shows    |
| `SNUGDOG_Terrier_still.webp`      | Copy of the hero-standing still                   |
| `SNUGDOG_Terrier_turntable.webp`  | Eight views as a 4x2 contact sheet                |
| `SNUGDOG_Terrier.glb`             | Light realtime model, 1K maps                     |
| `SNUGDOG_Terrier_hero.glb`        | Detailed realtime model, 2K maps                  |

**The fur exists only in the stills.** It is several hundred thousand hair strands,
which a browser cannot draw. The GLBs carry the same rigged dog with a fur-grain
texture instead, so the site shows the stills by default (`MascotStage`) and offers
the realtime model only as an option.

## How the model is made

1. **Anatomy** (`anatomy.py`): every measurement in one place. Units are 1 = 10 cm,
   nose toward +X, +Z up, the dog's left is +Y, paws on Z = 0.
2. **Volumes to skin** (`modeling.py`): tubes and ellipsoids are fused with a voxel
   remesh, smoothed, and retopologised to even quads (QuadriFlow). Ears are thin
   flaps joined into the skin.
3. **Face**: large eyes with visible whites, seated by raycasting onto the skull.
   Both eyes share one line of sight (`GAZE`), which is what gives the sideways
   glance. Lid shells pivot on the eye's axis, so a blink is one rotation.
4. **Skin material**: per-vertex colour plus a procedural grain, baked to maps.
5. **Groom** (`groom_groups`, `add_fur` in `build_mascot.py`): two vertex groups set
   how long the fur grows and where it grows at all. Long on beard, brows, chest,
   belly and legs; short on the skull and around the eyes; none over the eyes, nose
   or inside the ears. Strands are charcoal with a share of pale hairs.
6. **Rig** (`rig.py`): armature with automatic weights; ears weighted by hand. Eyes,
   lids and nose ride the `Head` bone; the collar rides `Neck`.
7. **Poses**: readable bone turns, stored as one action per pose on NLA tracks and
   exported as named clips.

### Fur settings worth knowing

- In advanced hair mode a strand's length is about four times the size of its start
  velocity (`normal_factor` plus `object_align_factor`), scaled by the `fur_length`
  group. `hair_length` has little effect.
- The strands use a plain Principled BSDF, not the Principled Hair BSDF, which
  rendered far too pale in this studio lighting.

## Hierarchy

```
SNUGDOG_Terrier              (armature)
|-- Root                     hips; move/tilt the whole dog
|   |-- Body -> Chest -> Neck -> Head -> Muzzle
|   |                |      |      |-- Ear_L -> Ear_L_2
|   |                |      |      |-- Ear_R -> Ear_R_2
|   |                |      |      |-- Eye_L, Eye_R            (rigid meshes)
|   |                |      |      |-- Lid_U_L, Lid_U_R        (rigid meshes, blink)
|   |                |      |      |-- Lid_D_L, Lid_D_R        (rigid meshes)
|   |                |      |      `-- Nose                    (rigid mesh)
|   |                |      `-- Collar                         (rigid mesh)
|   |                |-- Leg_FL -> Paw_FL
|   |                `-- Leg_FR -> Paw_FR
|   |-- Leg_BL -> Paw_BL
|   |-- Leg_BR -> Paw_BR
|   `-- Tail -> Tail_2 -> Tail_3
`-- Skin / Skin_Hero         (one skinned mesh: body, head, legs, paws, tail, ears)
```

## Pose library

| Clip                   | Description                                     |
| ---------------------- | ----------------------------------------------- |
| `Pose_01_HeroStanding` | One front paw lifted, sideways glance           |
| `Pose_02_Curious`      | Head tilt                                       |
| `Pose_03_Walking`      | Mid-stride, diagonal legs                       |
| `Pose_04_Sitting`      | Sit                                             |
| `Pose_05_LookingBack`  | Body away, head turned back over the shoulder   |

To add a pose, add an entry to `POSES` in `rig.py` and a camera to `VIEWS` in
`build_mascot.py`. Steps are applied children first, and roll/pitch before yaw.

## Known limits

- **Not film quality.** The reference is a hand-sculpted, hand-groomed studio
  character. This is a scripted model: the fur and eyes carry the likeness, but the
  face has no sculpted lips, teeth, tongue or mouth interior, and the brows cannot
  move independently.
- **Realtime has no fur** (see above).
- **Sitting is approximate:** there is no IK and the hind legs fold with two bones.
- **One expression.** The gaze direction and lid opening are fixed at build time.
